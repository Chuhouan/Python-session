# Python 零基础 · 第一阶段

一个纯静态的零基础 Python 学习网站，浏览器里直接运行 Python（Pyodide），无需安装任何东西。面向完全零基础的人文社科学习者，中英对照，先通用案例、后社科场景。

## 功能

- **9 个单元 · 25 个小节**：起步 → 数据类型 → 字符串 → 输入输出 → 条件 → 循环 → 列表 → 字典 → 函数
- **浏览器内写代码**：真实 Python 环境（Pyodide），点「运行」即出结果
- **练习驱动解锁**：选择题 / 填空题 / 代码题，全通过才解锁下一节
- **SRS 间隔复习**：1 / 3 / 7 / 14 / 30 天排期，到期提示复习
- **新手友好报错**：把 Traceback 翻译成「是什么 / 怎么改」的中英对照
- **内置 AI 助教**：DeepSeek 浏览器直连，引导式答疑（自填密钥）
- **进度本地保存** + 导出 / 导入备份

## 本地预览

需要 Node.js（仅用于启动静态服务器，站点本身零依赖）：

```bash
node server.mjs
```

浏览器打开 http://localhost:5500

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，把这些文件推上去。
2. 仓库 Settings → Pages → Source 选 `main` 分支、根目录。
3. 稍等片刻，访问 `https://你的用户名.github.io/仓库名/`。

## 使用 AI 助教

点左侧「设置」，填入你的 DeepSeek API 密钥，保存。密钥只存在你浏览器的本地存储里，不会上传、不会写进源码。

## 技术栈

原生 ES 模块 + Pyodide（Web Worker）+ 手写 CSS 设计系统，无构建步骤、无框架。Pyodide 走 jsdelivr CDN（含 gcore 回退）。
